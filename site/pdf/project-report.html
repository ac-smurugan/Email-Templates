Summary

Description

Remote code execution via JNDI lookup in log4j-core 2.14.1 was found in example-corp/payments-api.

Steps To Reproduce

  1. Sign in as a test customer.
  2. Send the request below with the payload in the search field.
GET /api/v2/orders?q=%27%20OR%201%3D1-- HTTP/1.1
Host: api.example.com

Mitigation

Upgrade to the patched version and redeploy. Until then, block the pattern at the WAF.

Impact

An unauthenticated attacker could read or change customer data.
